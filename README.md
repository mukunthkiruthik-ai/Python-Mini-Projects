# 🐍 Python Mini Projects

> A collection of beginner-friendly Python mini projects built while learning AI & Data Science at KPRIET.

## 📌 About

This repository contains fun and practical Python mini-projects that I built as a first-year B.Tech AI&DS student. Each project demonstrates different Python concepts and problem-solving skills.

## 🚀 Projects

| # | Project | Description | Concepts Used |
|---|---------|-------------|---------------|
| 1 | [🔢 Number Guessing Game](number_guessing_game.py) | Guess the random number in limited attempts | Random, Loops, Conditionals |
| 2 | [🔐 Password Generator](password_generator.py) | Generate secure random passwords | String, Random, Functions |
| 3 | [📊 Student Grade Analyzer](grade_analyzer.py) | Analyze and visualize student grades | Lists, Functions, Statistics |
| 4 | [🧮 Unit Converter](unit_converter.py) | Convert between various units | Functions, Dictionaries |

## 🛠️ How to Run

```bash
# Clone the repository
git clone https://github.com/mukunthkiruthik-ai/Python-Mini-Projects.git

# Navigate to the project
cd Python-Mini-Projects

# Run any project
python number_guessing_game.py
```
